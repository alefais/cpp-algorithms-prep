# Algorithms

```bash
cd cpp-algorithms-prep
```

## Vectors

### Build and Run

#### Two Sum

```bash
./tools/build-example.sh algorithms/01_vectors/two_sum.cpp

./build/bin/algorithms/01_vectors/two_sum

# use -d flag to print the hash map content
./build/bin/algorithms/01_vectors/two_sum -d
```

#### Two Sum (sorted)

```bash
./tools/build-example.sh algorithms/01_vectors/two_sum_sorted.cpp

./build/bin/algorithms/01_vectors/two_sum_sorted

# use -d flag to print the steps taken and the values of i and j at each step
./build/bin/algorithms/01_vectors/two_sum_sorted -d
```
